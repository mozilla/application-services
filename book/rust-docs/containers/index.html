Storage for Firefox containers.

The crate owns the container list, the shape of the document it is stored in, and the migrations between that document’s versions. It does not own the storage itself and never touches the filesystem: ContainersStore hands the serialized bytes to its callback, and where they end up and how durably is the embedder’s decision.
