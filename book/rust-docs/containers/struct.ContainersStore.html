pub fn new( bytes: Option<Vec<u8>>, default_identities: Option<Vec<DefaultIdentity>>, callback: Box<dyn ContainersCallback>, ) -> Result<Self, InitError>

Seeds the store from a stored document, or from the default identities when bytes is None. If a migration ran, the document is persisted before this returns.

default_identities replaces the shipped public identities, for embedders that let enterprise policy define them. They are consulted whether or not there is a stored document: the label of a default container the user has not renamed comes from them, since it is not stored.

Source

pub fn unset_callback(&self)

Drops the callback, so that a late mutation during teardown cannot reach an embedder that is already gone.

One way: there is no putting it back. From here on the store keeps working in memory but persists nothing.
