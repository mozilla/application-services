7//! Storage for Firefox containers.
8//!
9//! The crate owns the container list, the shape of the document it is stored
10//! in, and the migrations between that document's versions. It does not own the
11//! storage itself and never touches the filesystem: [`ContainersStore`] hands
12//! the serialized bytes to its callback, and where they end up and how durably
13//! is the embedder's decision.
