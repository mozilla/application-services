Expand description

Custom lints for Nimbus feature manifests.

Where validation asks whether a manifest can generate working code, these ask whether the feature is one an experiment owner can work with. They never stop code generation, and they’re reported by nimbus-fml lint alone.

A lint can be silenced by a no-lint list on a feature, a top level no-lint list, or --allow/--deny.
